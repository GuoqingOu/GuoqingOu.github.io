# Guoqing Ou - Academic Homepage

A static academic homepage designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public repository on GitHub.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

The site uses only HTML, CSS, and JavaScript. No build process or package installation is required.

## Update

- Edit page content in `index.html`.
- Edit design and responsive layout in `styles.css`.
- Replace files in `assets/` while retaining the existing filenames to update the portrait or public CV.
